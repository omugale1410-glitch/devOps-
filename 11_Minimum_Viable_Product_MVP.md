# 11. Minimum Viable Product (MVP)

The MVP is intentionally limited to the capabilities required to demonstrate the central academic-management workflow.

## 11.1 MVP Scope

| Feature | MVP Capability | Main Users |
| --- | --- | --- |
| Student Registration | Create and maintain essential student information | Administrator |
| Record Management | View and update authorized student academic records | Administrator, Faculty |
| Attendance | Record and review attendance | Faculty, Student |
| Academic Report | Produce a structured academic summary | Administrator, Authorized Staff |

## 11.2 Excluded from the First Release

- Predictive analytics
- Advanced dashboards
- Dedicated mobile application
- External institutional integrations
- Complex automation
- Features that are not required to validate the core workflow

## 11.3 MVP Validation

The MVP should answer four practical questions:

1. Can an authorized administrator create a student record?
2. Can faculty manage attendance efficiently?
3. Can a student retrieve permitted academic information?
4. Can authorized staff produce a useful academic report?

Features outside these questions can be considered after the core workflow has been validated.
