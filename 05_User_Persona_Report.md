# 5. User Persona Report

Personas provide representative users for evaluating workflows and interface decisions.

## Persona 1 — Student

**Name:** Riya Kulkarni  
**Role:** Undergraduate learner

**Goals**
- Check personal academic information.
- Review attendance.
- View examination results.
- Understand current academic status.

**Pain Points**
- Information can be distributed across different sources.
- It may take effort to determine which record is current.

**Expectations**
- Simple navigation.
- Accurate information.
- Fast access to frequently used records.
